Menjembatani Ruang Abstraksi Desain dengan Realitas Rekayasa Kode

Perkembangan industri perangkat lunak modern tidak lagi memisahkan desainer dan insinyur komputasi ke dalam silo terisolasi. Melalui workshop intensif berdurasi 3 jam ini, mahasiswa kelas TI-2024 akan dibekali paradigma arsitektur produk digital: bagaimana variabel visual diterjemahkan ke dalam token atomik sistematis, menyusun hierarki komponen skalabel, serta mengeliminasi friksi implementasi antarmuka pada level kode Tailwind & Flutter.

Silabus Kurikulum Workshop 3 Bagian Modul Terstruktur

1
09.00 - 09.50 WIB (50 Menit) Anatomi & Arsitektur Design Tokens

Membedah penamaan semantik variabel warna, tipografi berpasangan, sistem skala spasi 4px, serta penanganan mode kontras rasio WCAG AAA.

draw Figma Variables
2
09.50 - 10.45 WIB (55 Menit) Design Systems Scalability & Component Matrix

Membangun multi-state variants, dynamic auto-layout constraints, dan dokumentasi living styleguide yang siap diadopsi lintas platform.

widgets Design Systems
3
10.45 - 12.00 WIB (75 Menit) Kolaborasi Designer-Engineer & Live Handoff

Simulasi sinkronisasi JSON tokens ke file tailwind.config.js langsung di VS Code, uji regresi layout, dan studi kasus proyek riil.

terminal Live Coding
Alokasi Waktu Pembelajaran Terpandu Total: 180 Menit
