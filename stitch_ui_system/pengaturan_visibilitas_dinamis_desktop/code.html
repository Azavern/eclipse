Prinsip Keamanan RLS & Aturan Ceiling Halaman

Ceiling Rule: Hak akses seksi turunan tidak dapat melampaui kelonggaran hak akses halaman pembungkusnya. Fail Closed: Anomali sesi otomatis membatasi akses ke level 'Pengelola Kelas'. Atribut berstatus Hanya Saya dienkripsi dan tidak bisa dibuka oleh admin/ketua kelas lain sekalipun.

Kebijakan Aktif: Realtime Database Mirroring Perubahan disinkronkan ke token JWT klien secara instan.

CREATE POLICY "dynamic_visibility_check"
ON public.class_sections
FOR SELECT USING (
  auth.has_permission(section_key, current_user)
  AND (ceiling_scope >= target_scope)
);

Setiap perubahan di formulir ini langsung mengompilasi ulang fungsi current_user_can_access() di schema Supabase.
