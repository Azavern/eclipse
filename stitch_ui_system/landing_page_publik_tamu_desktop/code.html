Tinjauan Akademik Publik

Mata Kuliah Terintegrasi (Semester Ganjil)

Menampilkan 4 dari 8 Mata Kuliah Terbuka
TI-2101 3 SKS

Struktur Data & Algoritma

Representasi graf, pohon biner, algoritma traversal, kompleksitas Big-O, dan implementasi memori dinamis menggunakan C++.

Dosen: Tim Pengampu SDA description
TI-2102 3 SKS

Sistem Manajemen Basis Data

Normalisasi relasional hingga 3NF/BCNF, indeks PostgreSQL, transaksi ACID, konkurensi, dan introduksi basis data NoSQL.

Dosen: Lab Basis Data description
TI-2103 2 SKS

Arsitektur & Organisasi Komputer

Rancangan CPU von Neumann, set instruksi RISC-V, hierarki memori cache, saluran pipelining, dan logika digital sekuensial.

Dosen: Lab Hardware TI description
TI-2104 3 SKS

Pemrograman Berorientasi Objek

Enkapsulasi, pewarisan polimorfisme, SOLID design principles, generic programming, dan unit testing otomatis via Gradle.

Dosen: Tim Rekayasa RPL description
